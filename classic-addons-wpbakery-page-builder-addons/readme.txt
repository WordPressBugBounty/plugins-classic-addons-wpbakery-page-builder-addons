== Description ==

**Classic Addons for WPBakery Page Builder** is a feature-rich addon bundle that enhances the functionality of the [WPBakery Page Builder (formerly Visual Composer)](https://1.envato.market/gbGbzO) plugin. This plugin offers over **24+ highly customizable design elements** to help you create professional-looking websites easily — **no coding required**.

Whether you're building landing pages, portfolios, business sites, or personal blogs, these pre-designed blocks help you create interactive and modern layouts quickly. Each element comes with its own customization options to match your website’s style perfectly.

[More Info / Live Demos](https://classicaddons.com/)

### ✨ Key Features:
- Over **24 flexible and modern design elements**
- Option to enable/disable any specific module
- 100% responsive and mobile-friendly
- Easy-to-use interface inside WPBakery Page Builder
- Lightweight and performance-optimized
- Perfect for freelancers, agencies, and developers

You can create beautiful layouts with **unlimited combinations** of settings and styles. From animated counters to testimonial sliders and interactive banners, Classic Addons gives your website a fresh and professional touch.

== Installation and Usage ==

1. Install and activate the [WPBakery Page Builder](https://1.envato.market/gbGbzO) plugin (required).
2. Install and activate the Classic Addons plugin.
3. Once activated, the new addons will be available in the WPBakery interface.
4. Drag and drop any addon onto your page and customize its settings easily.

= 4.2 - 10 September 2026 =
* Developer: all plugin-defined file-scope variables now carry the `cawpb_` prefix (settings files now define `$cawpb_params`; the loader still reads the legacy `$params` from older companion files, so third-party settings files keep working).
* Developer: renamed internal hooks to the `cawpb_` prefix — `wcp_testimonial_display_rating` → `cawpb_testimonial_display_rating`, `wcp_testimonial_display_company` → `cawpb_testimonial_display_company`, `caw_render_icon_component` → `cawpb_render_icon_component`, `caw_render_button_component` → `cawpb_render_button_component`, and the `caw_get_image_by_size` filter → `cawpb_get_image_by_size`. If you hooked into the old names, update to the new ones.
* Compatibility: No shortcode base, CSS class, markup or option changes; existing content and integrations are unaffected.
* Developer: Added public extension hooks so external companion plugins (e.g. Classic Addons Pro) can register additional addons and inject extra params into existing widgets — filters `cawpb_modules`, `cawpb_settings_modules`, `cawpb_module_paths`, `cawpb_module_settings`, `cawpb_params_{shortcode_base}`, `cawpb_params`, plus actions `cawpb_before_addons_init`, `cawpb_init`, `cawpb_enqueue_front_scripts`, `cawpb_admin_enqueue_scripts`, `cawpb_register_components`
* Developer: Added feature-gate helpers `cawpb_is_pro()` and `cawpb_can( $feature_key )` (default false, filterable by companion plugins)
* Fixed WPBakery 9.x deprecation notices for the colorpicker `default_colorpicker_color` attribute across all affected elements.
* Fixed WPBakery 9.x deprecation notice for `vc_map_add_css_animation()` in the Alert Box element, with a version-safe fallback for older WPBakery versions.
* Aligned the internal version constant with the plugin header.
